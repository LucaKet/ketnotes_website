pg2: In the $2$D model proposed by Read and Green (2000) Majorana zero modes appear in vortex cores.

The Berry phase / connection / curvature can all be derived from gauge invariance principles: The connection is a natural measure of the rate of change of a wave function in momentum space, but it's not gauge invariant. Its rotor is (curvature), as is its line integral along a closed loop ‘C’ (which is the Berry phase).

\[ A(k) = \langle u(k) | \partial_k | u(k)\rangle \tag{1} \]

Berry connection.

\[ F(k)_{ij} = \partial_{k_j} A_{k_i} - \partial_{k_i} A_{k_j} \tag{2} \]

Berry curvature.

\[ B(k) = i \oint_C (dk \ A(k)) \tag{3} \]

Berry phase.

pg3: For a time reversal symmetric system the Chern number $Q$ is necessarily $0$, since

\[ F(k) \rightarrow -F(k), \tag{4} \]

thus integrating over the whole BZ gives

\[ Q = -Q \ \rightarrow \ Q = 0. \tag{5} \]

In 2D, if no symmetry is present, the Quantum Hall state is the only topologically non trivial allowed state!

pg4: Kramers degeneracy.

For a spinful system one can define the Spin Chern number. Start by dividing the hamiltonian into spin sectors: \[ H = \begin{pmatrix} H_{\mathrm{up}} & 0 \\ 0 & H_{\mathrm{down}} \end{pmatrix} \tag{6} \] each sector is not TR invariant (spin flips under T), thus it can have a non-zero Chern number. This is the spin Chern number.

Something (slightly) more complicated involving Kramers pairs is needed in the case of spin-orbit coupled systems. This index defines Quantum SPIN Hall insulators.
