Two-particle state: spin

General

Given two particles of spin-quantum number $s_1$ and $s_2$, one can describe their combined wavefunction. This wave function will be of spin-quantum number $s$, where $s$ can take values in the range: \[ |s_1 - s_2| < s < |s_1 + s_2|. \tag{1} \] In the case of $s_1 = s_2 = 1/2$, $s = \{0,1\}$ which are referred to as singlet and triplet states.

Then one must choose the set of commuting operators with which to describe spin. Two options are

  • $\{S^2, S_z\}$ → referring to the total/z-projection spin of the entire wave function
  • $\{S_{1z}, S_{2z}\}$ → referring to the z-spin projections of the $2$ individual particles

Spin singlet vs triplet

It is with the first set of operators that one can appreciate the difference between singlet and triplet states. There are $4$ possibilities

  • singlet state ($1/4$) : defined by $s = 0 \ \rightarrow \ S^2 = 0, \ S_z = 0$
  • triplet states ($3/4$) : defined by $s = 1 \ \rightarrow \ S^2 = 2, \ S_z = \{-1,0,1\}$

These correspond, in the second operator basis, to respectively

  • singlet : $\psi \ = \frac{1}{\sqrt{2}}(|1/2 , -1/2\rangle - |-1/2, 1/2\rangle)$
  • triplet : $\psi \ = \frac{1}{\sqrt{2}}(|1/2, -1/2\rangle + |-1/2, 1/2\rangle) \ ; \ |1/2, 1/2\rangle \ ; \ |-1/2, -1/2\rangle$

Eigenvalues

The eigenvalues of these operators read: \[ S^2 \rightarrow s(s+1), \qquad S_z \rightarrow m \tag{2} \] where $m$ takes values in $\{-s, -s+1, \dots, 0, \dots, s-1, s\}$ (either for the single particle or the full state).

This is useful for computing the product of spin operators expressed in terms of Pauli matrices: Spin as Pauli matrices, finding the eigenvalue of the product \[ \vec{S}_1 \cdot \vec{S}_2 \tag{3} \] can be done by writing \[ S^2 = S_1^2 + S_2^2 + 2 \vec{S}_1 \cdot \vec{S}_2 \ \ \rightarrow \ \ \vec{S}_1 \cdot \vec{S}_2 = \frac{1}{2} [ S^2 - S_1^2 - S_2^2 ] \tag{4} \] And plugging in the eigenvalues $s_k(s_k + 1)$ for $k = 1,2$ gives the answer for the eigenvalue of the product of the operators. This distinguishes, in the case of $s_1 = s_2 = 1/2$, between singlet and triplet states. For singlets $s = 0$ → $\vec{S}_1 \cdot \vec{S}_2 = -1/4$, For triplets $s = 1$ → $\vec{S}_1 \cdot \vec{S}_2 = 3/4$.
