Creation and annihilation operator commutation rules

Many calculations in the II quantization formalism make use of the commutation rules between the constituent objects, namely the creation and annihilation operators.

These commutation rules stem from the basic principles of QM and they give rise to bosonic and fermionic statistics.

We define a fermionic creation (annihilation) operator pair $C^\dagger_{\alpha} \ (C_{\alpha})$ by the relations ($\alpha$ and $\beta$ are generic sets of quantum numbers, e.g. spin, momentum, orbital, ...): \[ \{C^\dagger_\alpha, C^\dagger_\beta\} = 0 \ \rightarrow \ C^\dagger_\alpha C^\dagger_\beta = - C^\dagger_\beta C^\dagger_\alpha \tag{1} \] this is telling us that fermions gain a “$-$” once you exchange them. The same is true if annihilation operators are substituted for the creation ones ($C^\dagger \rightarrow C$).

further we require: \[ \{C_\alpha, C^\dagger_\beta\} = \delta_{\alpha, \beta} \tag{2} \]

The bosonic creation and annihilation operators respect the same rules, with $[*,*]$ instead of $\{*,*\}$ (commutators instead of anti-commutators). Their interpretation is that bosonic wave function do not gain a minus sign under exchange of particles, and that one can create as many bosonic excitations as one wishes with the same quantum numbers (as opposed to fermions which — in light of the second relation — only allow for one excitation per quantum number set).

N.B.: $\{a,b\} = ab + ba \ ; \ [a,b] = ab - ba$
