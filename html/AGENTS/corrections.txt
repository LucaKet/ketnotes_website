[R] spelling mistakes should always be corrected in the html 
  wiki.

[R] all inline numbers should be put between dollas signs:
  e.g.: ... using $2$ degenerate ... (from BdG Hamiltonian)
[R] same for math quantities, which should be inferred from context.
  e.g.: ..., $A$ is the Berry potential. ...(from Berry curvature
  as magnetic field)

[R] meta-notes (notes I write for my future self) like [Q:...],
  [Note:...] or [TBD:...] should be translated into 
  <code>[<b>Q/Note/TBD :<b>...] in the html code. See for example
  the [Q: why is the ...] in 'Dirac points 3D'.
  I have not been consistent in the meta notes of the .txt files 
  untill now, but will start to adopt the [Q/Note/TBD:...] 
  convention from now on

[R] Main note titles: do include connecting words which I omit in
  the file name. E.g. Eigenstates topological systems as monopoles -> Eigenstates _of_ topological systems as monopoles.
  The file name should however remain identical to the .txt one 
  (except the file extension, obiously). The indices should reflec
  the full title (including _of_), not the file name.

[R] Lit notes naming convention should follow: 
  Title (author, year or chapter if relevant), 
  see e.g. 'Superfluid He3 and unconventional superconductivity (Annett, Ch.7)'.
  Here too I will try to be more consistent and write the full note
  title in the .txt files going forwards.
  The indices should reflect the note title, the file name
  should be the same as the corresponding .txt file.

[R] If page numbers are reported in lit notes, they should be included as <b>pg X :</b> ... 
  See for example pg150 in the Annett note, apply to all.

  *...*, **...** (both) -> <b>...</b>
  _..._ -> <em>...</em>
  [Q/Note/TBD:...] (and only these) -> <code>[<b>Q/Note/TBD :</b>...]
